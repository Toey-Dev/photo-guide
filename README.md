# 📸 คู่มือถ่ายภาพ — Lumix G97

คู่มือถ่ายภาพฉบับครบ ดีไซน์สไตล์นิตยสาร ปรับเฉพาะสำหรับกล้อง **Panasonic Lumix G97** พร้อมเลนส์ **12–60mm** และ **25mm f/1.7** — ครอบคลุมตั้งแต่หลักการพื้นฐาน การจัดองค์ประกอบ การละลายพื้นหลัง ไปจนถึงค่าตั้งจริงในทุกสถานการณ์ตลอดทั้งวัน

🔗 **เว็บไซต์:** _(ใส่ลิงก์ Vercel ของคุณตรงนี้ เช่น https://photo-guide.vercel.app)_

| # | หัวข้อ | รายละเอียด |

| 02 | โหมด P / A / S / M | เลือกใช้เมื่อไหร่ พร้อมภาพแป้นหมุน |

| 06 | ค่าตั้งจริงตามช่วงเวลา | ตาราง + สูตรพร้อมใช้ 5 สถานการณ์ |

## 🎯 ปรับเฉพาะสำหรับ G97

- เซนเซอร์ Micro Four Thirds (crop factor ×2)
- ข้อจำกัด f/5.6 ที่ระยะ 60mm ของเลนส์คิต
- ระบบกันสั่นในตัว (IBIS)
- เพดาน ISO แนะนำที่ 3200

## 🚀 การ Deploy

เว็บนี้เป็น static site ไฟล์เดียว (`index.html`) ไม่ต้องมีขั้นตอน build

### ผ่าน Vercel (แนะนำ)

1. Push โปรเจกต์ขึ้น GitHub repo นี้
2. ไปที่ [Vercel](https://vercel.com) → **Add New… → Project**
3. Import repo `photo-guide`
4. ตั้ง **Framework Preset = Other** และเว้นช่อง Build Command ว่างไว้
5. กด **Deploy**

หลังจากนี้ทุกครั้งที่ push ไฟล์ใหม่ Vercel จะ deploy ให้อัตโนมัติ

### ดูแบบ local

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และรูป)
