Post-Processing Field Guide

แต่งภาพ RAW
ให้เป็นภาพในใจ

คู่มือแต่งภาพฉบับ Darktable — โปรแกรมแต่ง RAW ฟรี open-source ที่แทน Lightroom ได้จริง ตั้งแต่ติดตั้ง ลำดับการแต่ง โมดูลพื้นฐาน จนถึงสูตรลุคของเรา — ต่อยอดจากไฟล์ .RW2 ที่ถ่ายด้วย Lumix G97

01

เริ่มต้นใช้งาน + ลำดับการแต่ง

Darktable แบ่งเป็น 2 ห้อง: lighttable (คลังรูป · เหมือน Library ของ LR) และ darkroom (ห้องแต่ง · เหมือน Develop) — ตั้งค่า 2 อย่างนี้ให้เสร็จก่อนเริ่ม

⚙️ ติดตั้งครั้งแรก (สำคัญกับ G97 โดยเฉพาะ)

darktable.org ► download ► เลือก Windows · ต้องเป็นเวอร์ชัน 5.2 ขึ้นไป (ตัวล่าสุด 5.6 ใช้ได้เลย — คู่มือนี้เทียบกับ 5.6.0)
  1. โหลดเวอร์ชันล่าสุด (≥ 5.2) — การรองรับไฟล์ .RW2 ของ DC-G97 ถูกเพิ่มในเวอร์ชัน 5.2 · เวอร์ชันเก่ากว่านั้นจะขึ้น "not supported" เปิดไฟล์ไม่ได้
  2. เปิด OpenCL: ไอคอนเฟือง (preferences) ► processing ► ติ๊ก activate OpenCL support — โน้ตบุ๊กคุณมีการ์ดจอ RTX จะประมวลผลเร็วขึ้นหลายเท่า
  3. Import รูป: แท็บ lighttable ► import ► add to library (ชี้โฟลเดอร์รูป — ไฟล์อยู่ที่เดิม ไม่ถูกย้าย/ก๊อป)
  4. ดับเบิลคลิกรูป → เข้าห้อง darkroom เริ่มแต่งได้เลย · โมดูลทั้งหมดอยู่แผงขวา
เปิดรูปแล้วหน้าจอไม่เหมือนคู่มือ? เช็กมุมล่างขวาแผงโมดูล: module order — ถ้าขึ้น legacy แปลว่าคุณเปิดไฟล์ JPEG อยู่ (โปรแกรมใช้ workflow เก่า จะเห็น base curve และ history เริ่มด้วย orientation/display encoding แทน exposure/sigmoid) — ให้แต่งจากไฟล์ .RW2 แล้วทุกอย่างจะเป็น scene-referred ตามคู่มือนี้ · หาโมดูลไม่เจอ พิมพ์ชื่อในช่อง search modules by name or tag บนแผงขวาได้เสมอ · แถวไอคอนเหนือช่อง search คือ "กลุ่มโมดูล" — เรียงจากซ้าย: active (โมดูลที่เปิดใช้อยู่) · base · tone · color · correct · effect คลิกเพื่อกรองเฉพาะกลุ่มนั้น

🔁 ลำดับการแต่งมาตรฐาน (ใช้ได้เกือบทุกภาพ)

  1. สีถูกก่อน — ไวท์บาลานซ์ที่โมดูล color calibration
  2. สว่างพอดี — โมดูล exposure ดู histogram ประกอบ
  3. วางโทนรวม — sigmoid (คอนทราสต์หลัก)
  4. เก็บไฮไลต์/เปิดเงา — tone equalizer
  5. สี — color balance rgb (+ color zones ถ้าจะเจาะรายสี)
  6. รายละเอียด — denoise (profiled) และ diffuse or sharpen
  7. เก็บงาน — lens correction · crop · แต่งเฉพาะจุดด้วย mask
  8. export ตามปลายทาง
ใจความเดียวที่ต้องจำ: ตัวเลขจากคู่มือ Lightroom ใช้ตรง ๆ ไม่ได้ (สเกลคนละระบบ) — ทำตาม "เจตนา" ของแต่ละขั้นแล้วดูภาพเป็นหลัก ไม่ใช่ตามเลข
02

ทำไมต้องแต่งจากไฟล์ RAW

JPEG คือภาพที่กล้อง "ปรุงเสร็จ" แล้ว — RAW คือวัตถุดิบทั้งหมดที่เซนเซอร์เก็บได้ พื้นที่ให้แต่งต่างกันมหาศาล

RECOVER

กู้แสงได้

ดึงส่วนสว่างที่เกือบโพลน และเปิดเงาที่มืดให้เห็นรายละเอียดกลับมาได้ ซึ่ง JPEG ทำได้น้อยมาก — เคสหลังขาวที่ Toscana กู้จาก RAW ได้เพราะแบบนี้

WHITE BALANCE

ปรับ WB ฟรี

เปลี่ยนอุณหภูมิสีย้อนหลังได้เหมือนตอนถ่าย ไม่เสียคุณภาพ — เคสวันครึ้มที่ภาพติดเย็น แก้ทีหลังได้ทั้งชุด

NON-DESTRUCTIVE

ไม่ทำลายต้นฉบับ

Darktable เก็บการแก้เป็นไฟล์ข้าง ๆ ชื่อเดียวกันนามสกุล .xmp ไฟล์ RAW ไม่ถูกแตะเลย ลบ .xmp = กลับค่าเดิมทั้งหมด

ไฟล์ RAW ของ G97 คือนามสกุล .RW2 · วิธีตั้งกล้องเป็น RAW+Fine ดูได้ที่ คู่มือถ่ายภาพ หัวข้อ RAW vs JPEG
03

โมดูลพื้นฐาน · หัวใจ 5 ตัว

Darktable มีโมดูลเป็นร้อย แต่งานจริง 90% จบด้วย 5 ตัวนี้ — เทียบกับแผง Basic ของ Lightroom ได้ตรง ๆ

EXPOSURE

exposure

ความสว่างรวมของภาพ (เทียบ Exposure ของ LR) — สไลเดอร์เดียวจบ ปรับก่อนเพื่อให้ histogram อยู่กลาง ๆ แล้วค่อยไปเล่นโทน

WHITE BALANCE

color calibration

ไวท์บาลานซ์ยุคใหม่ (เทียบ Temp/Tint) — ใช้หลอดดูดสี (color picker) จิ้มจุดที่ควรเป็นสีเทา/ขาวในภาพ ให้โปรแกรมคำนวณ WB ให้เอง แม่นและเร็วมาก

TONE ENGINE

sigmoid

ตัววางโทน/คอนทราสต์หลักของภาพ (แนะนำแทน filmic rgb สำหรับมือใหม่ — ผลลัพธ์ใกล้ความเคยชินจาก LR กว่า) · สไลเดอร์ contrast กับ skew พอสำหรับงานส่วนใหญ่

HL / SHADOWS

tone equalizer

ตัวเดียวแทน Highlights / Shadows / Whites / Blacks ทั้งสี่ — ภาพถูกแบ่งเป็นโซนสว่าง-มืด แล้วดัน/กดแต่ละโซนอิสระ · ใช้แท็บ masking ก่อนถ้าโซนแบ่งไม่ตรง

COLOR

color balance rgb

ศูนย์รวมงานสี — แท็บ master มี vibrance/chroma (เทียบ Vibrance/Saturation) และแท็บ 4 ways คือ Split Toning เต็มรูปแบบ (แต้มสีเงา/กลาง/ไฮไลต์แยกกัน)

SPEED

quick access panel

แผงรวมสไลเดอร์ที่ใช้บ่อย (ไอคอนหัวใจเหนือแผงโมดูล) — งานเร็ว ๆ ไม่ต้องไล่เปิดทีละโมดูล ปรับ exposure/contrast/saturation จากที่เดียว

04

แต่งทีละขั้น (ทำตามได้เลย)

ลำดับมาตรฐานสำหรับทุกภาพ + สูตรลุค matte/pastel ประจำตัวของเราแบบกดตามได้

📋 ลำดับมาตรฐาน 10 ขั้น

  1. เปิดภาพใน darkroom → color calibration ใช้หลอดดูดสีจิ้มจุดสีเทา/ขาว ให้สีถูกก่อน
  2. exposure ปรับความสว่างรวมให้พอดี ดู histogram ประกอบ
  3. sigmoid ตั้งคอนทราสต์รวม (ค่าเริ่มต้นมักดีอยู่แล้ว ขยับทีละนิด)
  4. tone equalizer กดโซนไฮไลต์ลงกู้ฟ้า · ยกโซนเงาเปิดรายละเอียด
  5. color balance rgb เพิ่ม vibrance ตามรสนิยม
  6. เจาะรายสีด้วย color zones (เช่น ฟ้าเข้มขึ้น เขียวสดขึ้น)
  7. denoise (profiled) ถ้า ISO สูง · diffuse or sharpen เพิ่มความคม (ดูที่ซูม 100%)
  8. lens correction + crop จัดเฟรม/แก้เอียง
  9. แต่งเฉพาะจุดด้วย mask (หัวข้อ 09)
  10. export ตามปลายทาง (หัวข้อ 10)

🎞️ สูตร "Khao Yai Pastel" ฉบับ Darktable (ลุค matte/faded)

ใช้กับภาพแสงนุ่ม เช้า/เย็น · คู่กับสูตรในกล้องที่ตั้งไว้
tone curveยกจุดดำ (ปลายล่างซ้าย) ขึ้นเล็กน้อย tone equalizerกดโซนไฮไลต์ −0.5 ถึง −1 EV local contrastติดลบเล็กน้อย = ฟุ้งนุ่ม color balance rgbglobal chroma −5 ถึง −10% 4 waysเงาแต้มฟ้า · ไฮไลต์แต้มอุ่น

ทำครบแล้ว เซฟเป็น style ชื่อ "Khao Yai Pastel" (หัวข้อ 12) — รูปต่อ ๆ ไปกดใช้ทีเดียวได้ทั้งชุด · อยากได้เวอร์ชันสีอิ่ม (Fresh) ก็สูตรเดียวกันแต่ chroma เป็น +10% และไม่ลด local contrast

05

Tone Curve · เส้นโค้งโทน

โมดูล tone curve / rgb curve — เครื่องมือคุมความสว่างละเอียดกว่าสไลเดอร์ และเป็นหัวใจของลุค matte

S-CURVE & MATTE

สองท่าที่ใช้จริง

S-curve: กดจุดเงาลงนิด ดึงไฮไลต์ขึ้นนิด = คอนทราสต์นุ่มมีมิติ (ใช้กับลุค Clean Punch) · Matte lift: ลากจุดมุมล่างซ้าย (จุดดำ) ขึ้นตรง ๆ — ดำสุดจะกลายเป็นเทาจาง เกิดลุคฟิล์มซีดทันที นี่คือหัวใจของ Pastel · ใน darktable ใช้ได้ทั้ง tone curve และ rgb curve ผลใกล้กัน

06

Color Zones · ปรับสีเฉพาะ

โมดูล color zones = แผง HSL ของ Darktable — เลือกปรับ 3 มิติของแต่ละสี: hue (เฉด), saturation (ความสด), lightness (ความสว่าง)

HUE

เปลี่ยนเฉดสี

เช่น ดันเขียวใบไม้อมเหลืองให้เขียวสด หรือฟ้าให้ออกครามขึ้น — เลือกแท็บ hue แล้วดึงเส้นตรงตำแหน่งสีนั้น

SATURATION

ความสดของสี

เพิ่ม/ลดความสดเฉพาะสี เช่น ลดความแดงของผิวที่จัดเกิน โดยไม่กระทบสีอื่น · มีหลอดดูดสีให้จิ้มจากภาพได้เลย

LIGHTNESS

ความสว่างของสี

กด lightness ของฟ้าลง = ท้องฟ้าเข้มดราม่า · เพิ่ม lightness โซนสีผิว = หน้าสว่างสุขภาพดี

สองท่ายอดนิยมของเรา: ฟ้าจืดวันแดดแข็ง (ลุค Clean Punch) → กด lightness ฟ้า + เพิ่ม saturation ฟ้าเล็กน้อย · เขียวทิวสนหม่นวันครึ้ม → เพิ่ม saturation เขียว + ดัน hue ไปทางเขียวสด
07

ความคม และ Noise

เก็บรายละเอียดด้วยสองโมดูล — ดูผลที่ระดับซูม 100% เสมอ

DIFFUSE OR SHARPEN

เพิ่มความคม

โมดูลอเนกประสงค์ — ไม่ต้องตั้งเอง เปิดเมนู presets แล้วเลือก sharpen demosaicing: AA filter เป็นจุดเริ่มที่ดีสำหรับไฟล์ G97 · อยากคมขึ้นอีกใช้ local contrast ค่าบวกเสริม (ตัวเดียวกับที่ติดลบทำลุคฟุ้ง)

DENOISE (PROFILED)

ลดเม็ด noise

จุดแข็งของ Darktable — มี "โปรไฟล์ noise" ของกล้องแต่ละรุ่นแต่ละ ISO เปิดโมดูลแล้วมันเลือกให้อัตโนมัติ ค่าเริ่มต้นมักดีเลย · ภาพกองไฟ/ดาว ISO 1600–3200 ของทริปเราคือลูกค้าประจำของโมดูลนี้

เซนเซอร์ M4/3 อย่าง G97 ที่ ISO สูง (1600+) ได้ประโยชน์จาก denoise (profiled) มากเป็นพิเศษ — เปิดเป็นนิสัยกับภาพกลางคืนทุกใบ แล้วค่อยลดแรงถ้ารายละเอียดหาย
08

แก้เลนส์ · ครอป · ปรับตรง

เก็บงานให้เนี้ยบ — แก้ความบิดเบี้ยวของเลนส์ และจัดเฟรมให้ลงตัว

LENS CORRECTION

แก้บิด/ขอบมืด

เปิดโมดูลแล้วโปรแกรมอ่านรุ่นเลนส์จาก EXIF เอง (ฐานข้อมูล lensfun รู้จักทั้ง 12–60 และ 25 f/1.7) แก้ภาพบิด ขอบมืด และ chromatic aberration ให้อัตโนมัติ

ROTATE & PERSPECTIVE

แก้เส้นเอียง/ตึกล้ม

โมดูล rotate and perspective — ปุ่ม automatic ดึงเส้นตึกให้ตั้งตรงเอง เหมาะภาพสถาปัตย์ Toscana มุมกว้างที่เส้นลู่

CROP

ครอป & ปรับตรง

จัดองค์ประกอบใหม่ เลือกอัตราส่วน (1:1 สำหรับ IG) เปิด guide กฎสามส่วนช่วยจัดเฟรม — ถ่าย 4:3 มาแล้วครอปทีหลังยืดหยุ่นสุด

09

แต่งเฉพาะจุด · Masking

ทุกโมดูลใน Darktable ใส่ mask ได้หมด (แถบไอคอนล่างของโมดูล) — ยืดหยุ่นกว่า LR ด้วยซ้ำ แค่ไม่มีปุ่ม AI คลิกเดียว

DRAWN MASK

วาดเลือกเอง

brush (แปรงทา) · ellipse/circle (วงรี — เหมาะครอบตัวคน) · gradient (ไล่ระดับ — เหมาะกดฟ้าจากด้านบน) · path (วาดเส้นรอบวัตถุ)

PARAMETRIC MASK

เลือกตามค่าภาพ

เลือกพื้นที่จากความสว่าง/สี เช่น "เฉพาะโซนสว่างสุด" หรือ "เฉพาะสีฟ้า" — นี่คือตัวแทน Select Sky ของ LR: parametric เลือกโทนฟ้า + gradient จากบน = mask ท้องฟ้าแม่น ๆ

COMBINE

ผสมสองแบบ

drawn ∩ parametric = วาดคร่าว ๆ แล้วให้เงื่อนไขค่าแสงเก็บขอบให้ เช่น วงรีครอบหน้าคน + จำกัดเฉพาะโทนผิว — ขอบเนียนไม่ต้องวาดเป๊ะ

REAL CASE

เคสจริง: ดึงหน้าคืน

ช็อต Toscana ที่ถ่าย EV ติดลบรักษาฉากหลัง → เปิดโมดูล exposure ตัวที่สอง (คลิกขวา ► new instance) + ellipse mask ครอบตัวแบบ + ดัน exposure ขึ้น ~1 EV = หน้าสว่างคืน ฉากหลังไม่ขาวเพิ่ม

สถานการณ์จริง · 4 เคสจากทริปเรา

ปัญหาที่เจอมาแล้วจริง ๆ กับวิธีแก้ใน darkroom ทีละโมดูล

☁️ เคส 1 · วันครึ้มภาพจืด+ติดเย็น (ช็อตเนินหญ้า SOL)

อาการ: เขียวหม่นเทา ภาพแบน โทนอมฟ้า — Pastel ในกล้อง + เมฆหนา = จืดสองชั้น
1 · color calibrationอุ่นขึ้น ~5500–6000K 2 · sigmoidเพิ่ม contrast เล็กน้อย 3 · color balance rgbvibrance +10–15% 4 · color zonesเพิ่ม sat เขียว 5 · tone equalizerยกโซนตัวแบบขึ้นนิด

ตัวการหลักคือ WB — แก้ให้อุ่นก่อนแล้วภาพจะ "หายป่วย" ไปครึ่งทาง ที่เหลือคือคืนชีวิตให้สีเขียว

🏛️ เคส 2 · คนในร่ม ฉากหลังขาวโพลน (Toscana f/3.x)

อาการ: ฟ้า/หอเอนหลุดขาว หน้าตัวแบบมืด — แสงต่างกัน ~2 สต็อป
1 · tone equalizerกดโซนไฮไลต์ −1 ถึง −1.5 EV 2 · exposure (instance ใหม่)+ ellipse mask ครอบคน ดัน +1 EV 3 · highlight reconstructionถ้าฟ้าหลุดสนิท เลือกโหมด inpaint

นี่คือเหตุผลที่ถ่ายรักษาฉากหลัง (EV ลบ) แล้วมาดึงหน้าคืนใน RAW — ถ้าถ่ายให้หน้าสว่างแต่แรก ฟ้าที่ขาวสนิทจะกู้ไม่ได้เลย · กันเกิดซ้ำหน้างาน: เช็กเลข f หลังสลับช่อง C ทุกครั้ง

🌙 เคส 3 · กลางคืน/กองไฟ ISO สูง

อาการ: noise เม็ดหยาบ + ภาพอมส้มจากไฟวอร์ม (ISO 1600–3200)
1 · denoise (profiled)เปิด — ค่าอัตโนมัติมักพอดี 2 · color calibrationลากเย็นลง ~3900K แก้ส้มเกิน 3 · color zonesลด sat ส้ม/แดงของไฟเล็กน้อย 4 · diffuse or sharpenเบามือ — ความคมกับ noise มาคู่กัน

ลำดับสำคัญ: ลด noise ก่อนค่อยเพิ่มความคม ไม่งั้นจะคมทั้งเม็ด noise · ภาพดาวจาก C3 ใช้สูตรเดียวกันแต่ยก exposure ก่อนแล้วค่อย denoise

🏙️ เคส 4 · อยากได้ลุค "Clean Punch" (แบบช็อต Tsingtao)

โจทย์: สีอิ่มสะอาด เงาดำจริง คมกลาง WB ตรง — ขั้วตรงข้ามของ matte
1 · sigmoidcontrast ปกติ–เพิ่มนิด (ไม่ยกจุดดำ!) 2 · color balance rgbvibrance +10% 3 · color zonesกด lightness ฟ้า + sat ฟ้าเล็กน้อย 4 · local contrastค่าบวกเบา ๆ

หัวใจคือ "สิ่งที่ไม่ทำ": ไม่ยกจุดดำ ไม่ลด local contrast ไม่แต้ม split tone — ปล่อยให้เงาดำสนิทแล้วภาพจะ "กรอบ" เอง · เหมาะเที่ยวเมือง ตึก แดดจัดฟ้าใส

เคล็ดลับ & ทำสูตรอัตโนมัติ (Styles)

จุดที่ Darktable เข้าทางสาย automation ที่สุด — สูตรที่ทำครั้งเดียว ใช้ซ้ำได้ทั้งทริป

⚡ เซฟสูตรเป็น Style (ทำครั้งเดียว ใช้ตลอด)

darkroom ► แผงซ้าย history ► ไอคอน ⊕ create style (อยู่ข้างปุ่ม compress history stack) ► ตั้งชื่อ เช่น "Khao Yai Pastel" ► เลือกเฉพาะโมดูลที่เป็น "ลุค" (tone curve, tone equalizer, color balance rgb, local contrast) — ไม่รวม exposure/crop ที่ต่างกันรายรูป
  1. แต่งรูปตัวแทน 1 ใบให้จบตามสูตรหัวข้อ 04
  2. กดไอคอน ⊕ create style ข้างปุ่ม compress history stack ตามพาธด้านบน
  3. เรียกใช้: ใน lighttable เลือกหลายรูปพร้อมกัน ► แผง styles ► ดับเบิลคลิกชื่อสูตร = ติดทั้งชุดในคลิกเดียว
  4. ขั้นเทพ: หน้า import ตั้ง apply style on import — รูปเข้ามาปุ๊บติดลุค Pastel อัตโนมัติทุกใบ แล้วค่อยจูนรายรูป
01 เทียบก่อน/หลังเป็นระยะ — กดปุ่ม take snapshot (แผงซ้าย) เก็บสถานะไว้ แล้วคลิกชื่อ snapshot เพื่อสลับเทียบสองเวอร์ชันบนจอเดียว
02 อยากลองสองลุคกับรูปเดียว — คลิกขวาใน lighttable ► duplicate ได้สำเนาเสมือน (ไม่เปลืองพื้นที่) แต่งแยกกันได้อิสระ เช่น Pastel หนึ่ง Clean Punch หนึ่ง
03 เก็บไฟล์ .RW2 ต้นฉบับ + ไฟล์ .xmp คู่กันเสมอ — ย้ายเครื่อง/ลงใหม่ การแต่งทั้งหมดตามไปด้วย
04 สำรอง 2 ที่เสมอ — และจากที่เคยตรวจกัน อย่าเพิ่งใช้ไดรฟ์ E: (SSD ที่เขียนช้าผิดปกติ) เก็บรูปทริปจนกว่าจะยืนยันว่าเสถียร
05 ถ่ายให้ดีตั้งแต่กล้อง (WB/EV ตามเช็กลิสต์) — RAW กู้ได้เยอะแต่ไม่ใช่เวทมนตร์ ฟ้าที่ขาวสนิทกู้ไม่กลับ
06 ดูภาพบนจอโน้ตบุ๊กตอนแต่งจริง อย่าตัดสินสีจากจอมือถือกลางแดด · แต่งเสร็จลองเปิดบนมือถือดูอีกรอบก่อนโพสต์
ไอเดียต่อยอด: ทำ style แยกตามทริป/ลุคให้ครบชุด — "Khao Yai Pastel" · "Fresh" · "Golden Hour Rich" · "Clean Punch" · "Night Denoise" (denoise+WB 3900K) แล้วชีวิตหลังทริปจะเหลือแค่ import → apply style → จูนนิดหน่อย → export เฟรม EXIF → โพสต์

แต่งจริงทีละคลิก · 3 สถานการณ์

จำลองว่าเพิ่งกลับจากถ่ายมา เปิด .RW2 ขึ้นมาแล้ว — ไล่ทำจริงตั้งแต่คลิกแรกจนกด export ตามลำดับโมดูลในแผงขวา (ชื่อตรงกับ Darktable 5.6.0)

① คู่ในคาเฟ่ Toscana — คนในร่ม ฉากหลังแดดจ้า

ปัญหา: หน้ามืด ฟ้า/ตึกหลังสว่างเกือบขาว · ไฟล์ 25mm f/1.7
  1. เปิดไฟล์ .RW2 ใน darkroom → เช็กมุมล่างขวาต้องเป็น scene-referred (ไม่ใช่ legacy)
  2. white balance — ปกติ "camera reference" ตั้งมาดีแล้ว ถ้าอมสีค่อยแตะ
  3. exposure — ลากขึ้นจนหน้าคนพอดี (ตอนนี้ฟ้าหลังจะโอเวอร์ ไม่เป็นไร)
  4. tone equalizer → แท็บ advanced → ลากโหนดฝั่งขวา (ไฮไลต์) ลง −1 ถึง −1.5 EV ดึงฟ้า/ตึกกลับมา
  5. ถ้าฟ้าบางจุดขาวสนิท เปิด highlight reconstruction → mode: inpaint opposed
  6. color balance rgb → global chroma +8% ให้ตึกพาสเทลมีสี
  7. crop → เปิด guide กฎสามส่วน จัดคนไว้เส้นซ้าย
  8. เก็บงานถ้าต้องดึงหน้าเพิ่ม: exposure คลิก ⧉ (new instance) → ท้ายโมดูลเลือก drawn mask → ellipse ครอบตัวคน → ดัน +0.7 EV เฉพาะในวง

หัวใจ: กดไฮไลต์ทั้งภาพก่อน แล้วค่อย mask ดึงเฉพาะหน้า — ได้ทั้งฟ้าและหน้าในภาพเดียว

② เนินหญ้า SOL — วันครึ้มฟ้าเทา ภาพจืดติดเย็น

ปัญหา: เขียวหม่น โทนอมฟ้า แบนไร้มิติ · ไฟล์ 12–60
  1. color calibration → เปิด → ใช้ CAT ดัน temperature อุ่นขึ้นราว +800 ถึง +1200K (แก้ตัวการหลัก)
  2. sigmoid → contrast 1.4–1.6 คืนมิติที่แสงครึ้มไม่มี
  3. color balance rgb → global chroma +12%
  4. color zones → แท็บ saturation → ยกเส้นช่วง เขียว ขึ้น (ใช้หลอดดูดสีจิ้มหญ้า)
  5. tone equalizer → ยกโซนกลาง (ตัวแบบ) ขึ้นเล็กน้อยให้เด่นจากฉาก
  6. haze removal → ค่าน้อย ๆ 15–25% ถ้าวันนั้นหมอกหนาจนภาพมัว

WB คือยา 80% ของเคสนี้ — แก้ให้อุ่นก่อนภาพจะหายป่วยทันที ที่เหลือคือคืนชีวิตให้สีเขียว

③ กองไฟกลางคืน — noise เยอะ อมส้ม

ปัญหา: เม็ด noise หยาบ (ISO 1600+) ไฟวอร์มอมส้มเกิน · ไฟล์ 25mm
  1. denoise (profiled) → เปิด → โปรไฟล์ตามกล้อง/ISO ขึ้นอัตโนมัติ ค่าเริ่มต้นมักพอดี (ทำก่อนเสมอ)
  2. exposure → ยกให้พอเห็นรายละเอียด อย่าฝืนสว่างจน noise โผล่
  3. color calibration → ลาก temperature เย็นลง (~3900K) แก้ส้มเกิน
  4. color zones → ลด saturation ช่วง ส้ม/แดง ของเปลวไฟลงนิด กันสีเลอะ
  5. diffuse or sharpen → presets → sharpen demosaicing เบา ๆ (คมมากจะดึง noise กลับ)
  6. tone equalizer → กดไฮไลต์ดวงไฟที่แตกโพลนลงเล็กน้อย

ลำดับตายตัว: ลด noise → ปรับแสง/สี → เพิ่มคม (นิดเดียว) · ถ้าเป็นภาพดาว C3 ยก exposure ก่อน denoise

ปิดจ๊อบเหมือนกันทั้ง 3 เคส: lens correction (แก้ขอบมืด/บิด) → เทียบ take snapshot กับต้นฉบับ → กลับ lighttable → (ครั้งแรกเซฟเป็น style) → export JPEG · sRGB · คง all metadata → เข้าแอปเฟรม EXIF → โพสต์ · จากนั้นรูปที่เหลือในทริปกดใช้ style เดียวจบแล้วจูนรายรูป
ถ่ายดี + แต่งเป็น = ภาพในใจ

คู่มือแต่งภาพฉบับ Darktable (ฟรี open-source) · คู่กับ คู่มือถ่ายภาพ Lumix G97 · เช็กลิสต์ SOL · คู่มือฟิลเตอร์
